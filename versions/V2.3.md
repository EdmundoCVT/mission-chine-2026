# V2.3 — Team workspace

Date: November 27, 2026

## Changes

- Replaced Chinese interface text with English and retained French as the second language across navigation, forms, statuses, descriptions and itinerary copy.
- Kept the Chinese names for Shanghai (上海), Jinan (济南), Guangzhou (广州), Foshan (佛山) and Shenzhen (深圳) beside their English names.
- Added a team dashboard for Edmond (Business & Strategy), Lourenco (Technical & Purchasing) and Valencia (Sourcing & Logistics), with daily assignments, deadlines and completion indicators.
- Added 15 editable task proposals with owner, planned date, deadline, city, priority, status and expected result. Filters cover owner, date, city and status.
- Linked the tasks to the itinerary days, added TSV copy for spreadsheet transfer and retained the Tencent Docs reference link.
- Kept tasks in browser local storage under `businessChine.tasks.v23`; the project JSON backup includes tasks and the existing itinerary data.

## Assumptions

- The supplied task list is preloaded as proposed work to validate, never as completed work or confirmed appointments.
- Initial priorities and city associations are editable planning suggestions. No supplier identity, quotation or booking is included.
- Tencent Docs remains the collaborative source of truth. This site does not synchronize between devices or users.

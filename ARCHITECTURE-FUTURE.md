# Évolution vers une version protégée

La V1 est statique et local-first. Une évolution compatible Cloudflare peut ajouter :

- Cloudflare Access pour l’accès privé ;
- Worker API pour séparer interface et données ;
- D1 pour les enregistrements structurés ;
- R2 pour les photos ;
- chiffrement, journal d’audit et sauvegardes automatisées ;
- modules d’assistance IA limités aux suggestions, analyses de marge, résumés et brouillons commerciaux.

Avant cette migration, ne pas saisir de données bancaires, mots de passe, pièces d’identité, informations confidentielles ou données sensibles de clients.
